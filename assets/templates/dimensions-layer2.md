# 第二层：分类一致性评估维度

> **适用范围**：第二层（分类一致性评估）。第一层评分标准见 `assets/templates/dimensions-layer1.md`，第三层评分标准内嵌于 `references/layer3-architecture.md`。

从以下 **8 个维度** 对每个分类（SKILL.md + 子文档作为整体）打分，每个维度 0-10 分。

> **前置条件**：第一层该分类下所有文件达标后，方可执行本评估。详见 `references/layer2-consistency.md`。

---

### D1(职责边界)：职责边界（权重 15%）

分类内文件职责无重叠、无遗漏，每个文件各管一块。

| 分数 | 标准 |
|------|------|
| 0-3 | 职责划分混乱，文件间大面积重叠且遗漏核心场景 |
| 4-6 | 存在明显重叠或遗漏 |
| 7-8 | 少量重叠（1-2 处）但无遗漏 |
| 9-10 | 职责清晰无重叠无遗漏 + 粒度合理 |

### D2(术语一致)：术语一致性（权重 10%）

同一概念在分类内所有文件中使用统一术语。

| 分数 | 标准 |
|------|------|
| 0-3 | 术语混乱，无法确定标准 |
| 4-6 | 大量术语不一致 |
| 7-8 | 核心术语统一，少量非关键术语不一致 |
| 9-10 | 全部术语统一 + 有术语表 |

### D3(交叉引用)：交叉引用（权重 10%）

文件间引用正确、可达，引用内容与目标文件匹配。

| 分数 | 标准 |
|------|------|
| 0-3 | 引用体系混乱 |
| 4-6 | 多处断链 |
| 7-8 | 引用路径正确但少量内容不匹配 |
| 9-10 | 所有引用正确可达 + 内容匹配 + 无循环 |

### D4(知识覆盖)：知识覆盖度（权重 15%）

分类领域核心场景无遗漏，知识体系完整。

| 分数 | 标准 |
|------|------|
| 0-3 | 知识体系不完整 |
| 4-6 | 存在核心场景遗漏 |
| 7-8 | 核心场景覆盖但少量边界场景缺失 |
| 9-10 | 核心场景全覆盖 + 层次完整 + 边界场景有说明 |

### D5(冗余检测)：冗余检测（权重 10%）

无跨文件大段重复，相同知识点集中定义、其他位置引用。

| 分数 | 标准 |
|------|------|
| 0-3 | 复制粘贴为主，无复用机制 |
| 4-6 | 大量冗余 |
| 7-8 | 少量冗余（1-2 处短段） |
| 9-10 | 零冗余 + 集中定义 + 引用复用 |

### D6(层级结构)：层级结构（权重 10%）

编号/分组/命名逻辑一致，文件组织有序。

| 分数 | 标准 |
|------|------|
| 0-3 | 无组织结构 |
| 4-6 | 组织混乱 |
| 7-8 | 基本一致但少量不规则 |
| 9-10 | 编号连续 + 分组一致 + 命名统一 + 排序合理 |

### D7(元数据一致)：元数据一致性（权重 15%）

子文档 frontmatter 与入口文件路由表一致，无孤立文件、无幽灵引用。

| 分数 | 标准 |
|------|------|
| 0-3 | 无路由表或子文档完全无组织 |
| 4-6 | 大量子文档与路由表不一致 |
| 7-8 | 少量不一致（<10%子文档）但无孤立/幽灵 |
| 9-10 | 全部一致 + 无孤立/幽灵 + 无重叠 + 触发条件匹配 |

### D8(工作流闭环)：工作流闭环（权重 15%）

入口文件声明的工作流被子文档完整覆盖，流程可闭环。

| 分数 | 标准 |
|------|------|
| 0-3 | 入口文件声明的工作流无子文档支撑 |
| 4-6 | 工作流与子文档脱节 |
| 7-8 | 主流程覆盖但少量分支缺失 |
| 9-10 | 全流程覆盖 + 分支有说明 + 端到端闭环 + 衔接流畅 |

---

### 评分计算

**加权总分 = D1×0.15 + D2×0.10 + D3×0.10 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.15 + D8×0.15**
