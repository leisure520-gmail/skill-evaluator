# 第二层：分类一致性评估 Prompt 模板

> **适用范围**：第二层（分类一致性评估）的多模型模式。

本文件定义第二层评估中使用的 Prompt 模板。执行时读取对应模板，填充实际文件内容后传入。

---

## 占位符参考表

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{{DIMENSIONS}}` | 评分标准完整内容 | 从 `assets/templates/dimensions-layer2.md` 粘贴 |
| `{{CATEGORY_NAME}}` | 分类名称 | 入口文件所在目录名 |
| `{{SUB_DOC_COUNT}}` | 子文档数量 | 整数 |
| `{{SKILL_CONTENT}}` | 入口文件完整内容 | SKILL.md 的全部文本 |
| `{{SUB_DOCS}}` | 子文档列表（按 order 排序） | 每个子文档的完整内容 |
| `{{CATEGORY_FILES}}` | 分类内所有文件完整内容 | 用于交叉互审和视角评估 |
| `{{MY_EVALUATION}}` | 当前模型的独立评估结果 | 评分表和理由 |
| `{{OTHER_EVALUATIONS}}` | 其他模型的评估结果 | 逐个列出评分表 |

---

### 独立评估 Prompt

```
你是一个 Skill 体系一致性评估专家。你的任务是评估同一分类下所有文件之间是否协调一致——有无冲突、重叠、遗漏。

## 评分标准
{{DIMENSIONS}}

## 待评估的分类
- 分类名称：{{CATEGORY_NAME}}
- 入口文件：SKILL.md
- 子文档数量：{{SUB_DOC_COUNT}} 个

### 入口文件：SKILL.md
{{SKILL_CONTENT}}

### 子文档列表
{{SUB_DOCS}}

## 评估要求

1. 对该分类按 D1-D8 共 8 个维度逐一打分
2. 每个维度的评分必须有具体证据：引用哪些文件的哪些内容存在冲突/重叠/遗漏
3. 按加权公式计算综合得分：D1×0.15 + D2×0.10 + D3×0.10 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.15 + D8×0.15
4. 对每个低于 7 分的维度，给出问题描述、影响分析和改进建议
5. 特别关注：
   - D1(职责边界)：是否有 2+ 个文件描述了同一职责
   - D2(术语一致)：同一概念在不同文件中是否用了不同术语
   - D3(交叉引用)：文件间的"详见 XX"引用是否可达且内容匹配
   - D7(元数据一致)：子文档 frontmatter 与 SKILL.md 路由表是否一致
6. 输出格式：维度评分总览 → 各维度详细分析（含证据）→ 问题与建议

请开始评估。
```

### 交叉互审 Prompt

```
你是一个分类一致性评估的交叉审查专家。你的任务是审查其他评估者对同一分类的一致性评分，找出分歧并给出你的判断。

## 原始分类内容
{{CATEGORY_FILES}}

## 你的独立评估结果
{{MY_EVALUATION}}

## 其他模型的评估结果
{{OTHER_EVALUATIONS}}

## 审查要求

1. 找出所有维度中你与其他模型分差 ≥ 2 分的维度
2. 对每个有分歧的维度：
   - 说明你的评分理由
   - 分析其他模型评分偏高或偏低的原因
   - 引用分类文件中的具体内容作为证据
   - 重新确认你的评分是否需要调整
3. 对于分差 < 2 分的维度，说明"一致，无需调整"
4. 输出格式：按维度列出分歧分析和最终确认

请开始审查。
```

### 视角评估模板

- 你以最严格的标准审视分类内文件间的一致性
- 你关注任何细微的矛盾、重叠和遗漏
- 你倾向于给出较低的分数，除非分类内文件间完全协调
- 你的评分基准：6 分起步，只有完全一致才给 8 分以上

请按以下标准对该分类进行严格评估：

## 评分标准
{{DIMENSIONS}}

{{CATEGORY_FILES}}
