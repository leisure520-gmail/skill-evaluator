

# 第一层：文件质量评估 Prompt 模板

> **适用范围**：第一层（文件质量评估）的多模型模式。

本文件定义第一层评估中使用的 Prompt 模板。执行时读取对应模板，填充实际文件内容后传入。

> **全量评估**：每个 Prompt 需包含入口文件（SKILL.md）和所有子文档的内容。

---

## 占位符参考表

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{{DIMENSIONS}}` | 评分标准完整内容 | 从 `assets/templates/dimensions-layer1.md` 粘贴 |
| `{{SKILL_CONTENT}}` | 入口文件完整内容 | SKILL.md 的全部文本 |
| `{{SUB_DOCS}}` | 子文档列表（含文件名和评估深度标注） | 按子文档 order 排序 |
| `{{FILE_CONTENT}}` | 单个文件内容 | 子文档的完整文本 |
| `{{RESOURCES}}` | 附带资源概况 | scripts/、references/、assets/ 目录文件列表 |
| `{{TARGET_SKILL}}` | 目标 Skill 完整内容 | 用于交叉互审和视角评估 |
| `{{MY_EVALUATION}}` | 当前模型的独立评估结果 | 评分表和理由 |
| `{{OTHER_EVALUATIONS}}` | 其他模型的评估结果 | 逐个列出评分表 |
| `{{PERSPECTIVE_A}}` | 严格派评估结果 | 评分表和分析 |
| `{{PERSPECTIVE_B}}` | 务实派评估结果 | 评分表和分析 |
| `{{PERSPECTIVE_C}}` | 专家派评估结果 | 评分表和分析 |

---

### 独立评估 Prompt

用于策略 A（subagent 并行）、策略 B（DeepSeek API）、策略 C（多视角）的独立评估阶段。

```
你是一个 Skill 质量评估专家。请对以下 Skill 进行客观、严格的评估。

## 评分标准
{{DIMENSIONS}}

## 待评估的 Skill 入口文件
{{SKILL_CONTENT}}

## 待评估的子文档
{{SUB_DOCS}}

### 01-base-entity.md（完整评估）
{{FILE_CONTENT}}

### 99-workflows/create.md（轻量评估：D3+D7）
{{FILE_CONTENT}}

## 附带资源概况
{{RESOURCES}}

## 评估要求

1. 对入口文件（SKILL.md）按 D1-D8 共 8 个维度逐一打分
2. 对有 frontmatter 的子文档按 D1-D8 完整评估
3. 对无 frontmatter 的子文档按 D3+D7 轻量评估
4. 对 assets/ 下的模板/示例/范本按 D3+D7 内容评估（不因缺少 frontmatter 扣分）
5. 每个维度的分数必须有明确的理由引用
6. 按加权公式计算综合得分：完整评估 D1×0.15 + D2×0.15 + D3×0.15 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.10 + D8×0.10；轻量/内容评估 D3×0.6 + D7×0.4
7. 对每个低于 9 分的维度，给出问题描述、影响分析和改进建议
8. 输出格式：先输出分类级评分总览，再输出每个文件的详细评分，最后输出问题与建议

请开始评估。
```

### 交叉互审 Prompt

用于策略 A 和策略 B 的交叉互审阶段。每个模型审查其他模型的评估结果。

```
你是一个 Skill 评估的交叉审查专家。你的任务是审查其他评估者对同一个 Skill 的评分，找出分歧并给出你的判断。

## 原始 Skill 内容
{{TARGET_SKILL}}

## 你的独立评估结果
{{MY_EVALUATION}}

## 其他模型的评估结果
{{OTHER_EVALUATIONS}}

## 审查要求

1. 找出所有维度中你与其他模型分差 ≥ 2 分的维度
2. 对每个有分歧的维度：
   - 说明你的评分理由
   - 分析其他模型评分偏高或偏低的原因
   - 引用 Skill 原文中的具体内容作为证据
   - 重新确认你的评分是否需要调整（如需要，给出调整后的分数和理由）
3. 对于分差 < 2 分的维度，说明"一致，无需调整"
4. 输出格式：按维度列出分歧分析和最终确认

请开始审查。
```

### 视角评估模板

用于策略 C（串行多视角）的独立评估阶段。三个视角按顺序在同一上下文中执行。

#### 视角 A：严格派评审

```

- 你倾向于给出较低的分数，除非 Skill 让你无可挑剔
- 你的评分基准：6 分起步，只有真正出色的部分才给 8 分以上

请按以下标准对 Skill 进行严格评估：

{{DIMENSIONS}}

3. 对无 frontmatter 的子文档按 D3+D7 轻量评估

5. 按加权公式计算综合得分

### 自我交叉审查模板

用于策略 C（串行多视角）的交叉审查阶段。

```
你已经以三个不同视角完成了对同一个 Skill 的独立评估：

### 视角 A（严格派）的评估结果
{{PERSPECTIVE_A}}

### 视角 B（务实派）的评估结果
{{PERSPECTIVE_B}}

### 视角 C（专家派）的评估结果
{{PERSPECTIVE_C}}

## 审查要求

1. 找出所有维度中三个视角分差 ≥ 2 分的维度
2. 对每个有分歧的维度，分析：
   - 分歧的原因（视角差异导致的还是 Skill 本身的问题）
   - 哪个视角的评分最有说服力，引用 Skill 原文证据
   - 建议的最终分数
3. 对于分差 < 2 分的维度，标注"一致"
4. 输出格式：按维度列出分歧分析和建议

请开始审查。
```
